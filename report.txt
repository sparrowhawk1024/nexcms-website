SECTION 1: PROJECT OVERVIEW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

NexStore is a full-featured headless e-commerce store with a cyberpunk/neon
aesthetic. It is powered by Next.js on the frontend and Contentstack as the
headless CMS backend. All content — products, reviews, banners, deals, and
categories — is managed entirely through Contentstack without touching code.

Design Theme:
  - Dark background (#0b0213 deep purple-black)
  - Fuchsia / Cyan neon accent color palette
  - Glassmorphism and glow effects
  - Geist Sans typography (Google Fonts via Next.js)
  - Premium cyberpunk aesthetic with micro-animations

Tech Stack:
  - Next.js 15.5.18 (App Router, React Server Components)
  - React 19
  - TypeScript 5
  - Tailwind CSS v4
  - Contentstack JavaScript SDK v3.15
  - Node.js (for upload scripts)

SECTION 8: CART SYSTEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

A global cart system was implemented using React Context API.

  contexts/CartContext.tsx
    - CartProvider wraps the entire app (in layout.tsx)
    - State: items[], each with { product, quantity }
    - Actions: addToCart, removeFromCart, updateQuantity, clearCart
    - The cart count badge shows in the Navbar automatically

  components/CartDrawer.tsx
    - Slides in from the right when cart icon is clicked
    - Shows all items with image, name, price × quantity
    - Quantity increase/decrease buttons
    - Remove button per item
    - Subtotal calculation
    - Checkout button (UI only — no payment integration yet)

  components/AddToCartButton.tsx
    - Used on ProductCard and product detail page
    - Shows "Add to Cart" if in_stock = true
    - Shows "Out of Stock" (disabled) if in_stock = false
    - Animates to "Added! ✓" for 1.5 seconds after clicking

Issue 1: Features group max 3 instances
  Error   : "The field cannot have more than 3 instances to meet the maximum
             requirement."
  Cause   : The 'features' group field in Contentstack was configured with a
             max of 3 instances. The upload script sent 8 features.
  Fix     : Reduced features to 3 per product, combining values where needed
             (e.g., "6000 mAh | 100W SuperVOOC" in one field).
  Future  : To allow more features, go to Contentstack → Content Models →
            product → Features group → Edit → increase max instances.

Issue 2: PowerShell execution policy blocking npm
  Error   : "npm.ps1 cannot be loaded because running scripts is disabled"
  Cause   : Windows PowerShell default execution policy is "Restricted",
             which blocks all scripts including npm.
  Fix     : Ran the command:
              Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser -Force
  Scope   : CurrentUser only (does not affect system-wide policy).
  Result  : npm run dev and all npm commands now work normally.

Issue 3: PowerShell && operator not supported
  Error   : "The token '&&' is not a valid statement separator"
  Cause   : PowerShell does not support && chaining like bash/cmd.
  Fix     : Run each command separately (git status, then git remote -v).

Issue 4: Git identity not configured
  Error   : "Author identity unknown — fatal: unable to auto-detect email"
  Cause   : First-time git commit on this machine with no global config.
  Fix     : Ran:
              git config --global user.name "sparrowhawk1024"
              git config --global user.email "premcnaik2004@gmail.com"
